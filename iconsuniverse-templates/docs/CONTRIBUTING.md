# Contributing Guide — IconsUniverse

## Branching
- `main` — production
- `dev` — staging/integration
- `feature/[name]` — individual work (e.g. `feature/pack-download-zip`)

## Commit Style
Conventional Commits — `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`

## Pull Requests
- [ ] Linked to an issue/task
- [ ] Passes lint + tests
- [ ] Matches `SCHEMA.md` / `API_Contract.md` exactly for any data or route changes
- [ ] Reviewed by project owner
